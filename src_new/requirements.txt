# ============================================================================
# Installation Instructions
# ============================================================================
#
# Option 1: Using conda (recommended for GDAL dependencies)
# ---------------------------------------------------------
# 1. Install conda/mamba
# 2. Create environment: conda env create -f src_new/environment.yml
# 3. Activate: conda activate offline-3d-gis-refactored
# 4. Install package: pip install -e .
#
# Option 2: Using pip only (requires system GDAL)
# ------------------------------------------------
# 1. Install system dependencies:
#    - Ubuntu/Debian: apt-get install gdal-bin libgdal-dev python3-dev postgresql-client
#    - macOS: brew install gdal postgresql qt6
#    - RHEL/CentOS: yum install gdal gdal-devel python3-devel postgresql
# 2. Create virtual environment: python3.11 -m venv venv
# 3. Activate: source venv/bin/activate
# 4. Install: pip install -r src_new/requirements.txt
# 5. Install package: pip install -e .
#
# Option 3: Server-specific installations
# ----------------------------------------
# Server 1 (Ingestion + Tile Serving):
#   pip install -r src_new/requirements.txt
#
# Server 2 (Query Service - minimal):
#   pip install fastapi uvicorn sqlalchemy psycopg[binary] pydantic pydantic-settings \
#               python-dotenv pyproj shapely httpx python-json-logger
#
# Desktop Clients:
#   pip install -r src_new/requirements.txt  # Full installation
#
# ============================================================================
# Offline/Air-Gapped Installation
# ============================================================================
#
# 1. On internet-connected machine:
#    pip download -r src_new/requirements.txt -d ./packages/
#
# 2. Transfer ./packages/ directory to air-gapped machine
#
# 3. On air-gapped machine:
#    pip install --no-index --find-links=./packages/ -r src_new/requirements.txt
#
# ============================================================================
# Notes
# ============================================================================
#
# - GDAL installation via pip can be problematic; conda is strongly recommended
# - Desktop clients require Qt6; backend services do not
# - Rust accelerators are optional; pure Python fallbacks exist
# - For production, pin all transitive dependencies using pip-compile
# - Redis is optional; file-based caching is the default
# - JWT/password hashing dependencies are optional (for future auth features)
