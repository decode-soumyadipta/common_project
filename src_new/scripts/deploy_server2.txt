## System Dependencies
- PostgreSQL client libraries (psycopg2/psycopg)
- PostGIS >= 3.3 (spatial extension)
- PyProj >= 3.6 (for coordinate transformations)

## Python Dependencies
- fastapi >= 0.115
- uvicorn >= 0.30
- pydantic >= 2.0
- pydantic-settings >= 2.5
- python-dotenv
- psycopg[binary] >= 3.2
- sqlalchemy >= 2.0
- pyproj >= 3.6
- shapely >= 2.0
- httpx >= 0.27

## Environment Variables Required
- DATABASE_URL
- API_HOST
- QUERY_SERVICE_PORT (default: 8003)
- ALLOWED_HOSTS
- LOG_LEVEL
- LOG_FORMAT
- LOG_OUTPUT_PATH

## Startup Scripts
- src_new/scripts/start_query_service.sh
- src_new/scripts/deploy_server2.sh (launches query service)

## Hardware Requirements
- CPU: Moderate multi-core (for query processing)
- RAM: 16GB+ (for query operations)
- Disk: Moderate capacity (primarily for logs)
- Network: LAN connectivity to PostGIS database and Server 1 (for tile requests)

## Notes
- Query Service does NOT require GDAL or raster processing libraries
- Communicates with Server 1 Tile Service via REST API for tile URLs
- All PostGIS queries use parameterized statements to prevent SQL injection
- Services bind to LAN interface only (not 0.0.0.0) for security
- Spatial indexing (GIST) is managed by PostGIS for optimal query performance
