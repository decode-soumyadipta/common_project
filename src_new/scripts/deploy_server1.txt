## System Dependencies
- GDAL >= 3.8.0 (with JPEG2000 support via libgdal-jp2openjpeg)
- Rasterio >= 1.3
- PostgreSQL client libraries (psycopg2/psycopg)
- PostGIS (for database connection)

## Python Dependencies
- fastapi >= 0.115
- uvicorn >= 0.30
- titiler.application >= 0.21
- pydantic >= 2.0
- pydantic-settings >= 2.5
- python-dotenv
- rasterio >= 1.3
- pyproj >= 3.6
- numpy >= 1.26
- psycopg[binary] >= 3.2
- sqlalchemy >= 2.0
- httpx >= 0.27

## Rust Dependencies (Optional Performance Accelerators)
- Rust toolchain >= 1.70
- PyO3 >= 0.20
- rusterize (for vector rasterization)
- maturin (for building Python extensions)

## Startup Scripts
- src_new/scripts/start_ingestion_service.sh
- src_new/scripts/start_tile_service.sh
- src_new/scripts/deploy_server1.sh (launches both services)

## Hardware Requirements
- CPU: High-performance multi-core (for GDAL processing)
- RAM: 32GB+ (for processing large rasters)
- Disk: Large capacity for DATA_ROOT storage (terabyte-scale)
- Network: LAN connectivity to PostGIS database and Server 2

## Notes
- Rust accelerators are optional; pure Python fallbacks are available
- Services communicate with Server 2 only via REST API endpoints
- All services bind to LAN interface only (not 0.0.0.0) for security
- TiTiler is configured to disable all external HTTP requests
